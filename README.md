# Mini Social Media Platform

## Description

A mini social media web application built using Django, HTML, CSS, JavaScript, and SQLite.

## Features

- User registration and login
- User profiles
- Create posts
- View posts
- Like and unlike posts
- Add comments
- Follow and unfollow users
- SQLite database

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## How to Run

```bash
pip install django
python manage.py migrate
python manage.py runserver
